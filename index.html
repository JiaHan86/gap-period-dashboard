Weekly rhythm (4–5 learning hours/day max)

Schedule blocks can be moved around to accommodate freelance work, errands, travel, or low-energy days. Gym time is separate and 3 times weekly.

  1. Monday — SQL deep learning 90m + practice 45m; Korean grammar/vocabulary 90m; English speaking 20m; Gym lower body 45–60m.
  2. Tuesday — Python/Pandas 90m + coding practice 45m; Korean reading 60–90m; business case / structured thinking 45m; English listening 20m.
  3. Wednesday — SQL/Python project 90m + practice 45m; Korean listening 60–90m; English writing 20m; Gym upper body 45–60m.
  4. Thursday — Marketing Analytics 90m + dashboard 45m; Korean writing 60–90m; MECE / 5 Whys 45m; English speaking 20m.
  5. Friday — Portfolio 90m + documentation 45m; Korean revision 60–90m; business podcast 20–30m; Gym full body/cardio 45–60m.
  6. Saturday — Korean review / mock 90m + review 45m; weekly case note 60m; reflection 20m. Keep the rest of the day free.
  7. Sunday — Rest / Life day by default. Optional walk, light reading, or meal prep. No catch-up obligation.
Freelance: Reserve 2–3 flexible blocks (1–2 hours) per week. On heavier freelance days, shrink the study plan—protect sleep and downtime.

Cloud sync: use the same account on phone and computer

To sync your check-ins across devices, this dashboard can connect to a Supabase cloud database. It needs a one-time setup of a project and table. The HTML file alone does not automatically sync between devices.

1. Create a free Supabase project

  1. Open Supabase and create a project.
  2. In SQL Editor, run the setup SQL from the accompanying setup guide.
  3. From Project Settings / API, copy Project URL and publishable (or anon) key.

2. Connect the dashboard

Cloud sync is not configured.

Use your own project credentials only. Never paste a service-role key here. Once connected and logged in, this page can store and fetch your day logs and note templates. Cloud functions require setup SQL and a hosted page.

3. Backup / restore (works offline too)

Export periodically and keep the backup somewhere safe. The local browser copy and cloud copy may need manual reconciliation if you edit offline.
